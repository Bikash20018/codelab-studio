----------------
CodeLab Studio is written in Python and uses only its standard library,
including Tkinter/Tk. The interpreter and Tk runtime are embedded by
PyInstaller. Python is distributed under the PSF License Agreement and Tcl/Tk
under the Tcl/Tk (BSD-style) license; both permit this redistribution.

bundling proprietary or differently licensed applications.


4. What this means for a student's own work
-------------------------------------------
Programs written in CodeLab Studio belong to whoever wrote them. Compiling with
GCC does not place a program under the GPL — that is the entire purpose of the
GCC Runtime Library Exception reproduced in this folder.
