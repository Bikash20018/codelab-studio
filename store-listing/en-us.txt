## ShortDescription
A C and C++ IDE built for students. The compiler, the debugger and the formatter are already inside - install it and write your first program a minute later. No setup, no accounts, no internet needed.

## Description
CodeLab Studio includes the MinGW-w64 build of the GCC compiler and the GDB debugger (GNU General Public License v3) and LLVM clang-format (Apache 2.0 with the LLVM exception). Everything is contained in this package - nothing is downloaded during or after installation. The app compiles and runs the C and C++ programs you write, locally on your own computer. Licences and the corresponding source for these components: https://github.com/Bikash20018/codelab-studio/blob/main/SOURCE.md

Getting started with C or C++ usually means installing a compiler, setting a PATH, and losing an afternoon before printing "Hello". CodeLab Studio removes that. Install it, press F11, and your program runs.

Write in a proper editor with syntax highlighting, line numbers, auto-indent, bracket matching, word suggestions as you type, find and replace, and tabs. Press F9 to compile, F10 to run, F11 for both. Compiler errors appear as red wavy underlines and in a Problems table - click one and you land on the line that caused it, with a plain-English explanation of what the message actually means.

Programs can run inside the Output panel, where you type input a line at a time and see output as it appears, or in their own console window so scanf and cin behave exactly as they do outside the IDE.

When something goes wrong, step through it. The Debug menu drives a real GDB session: set breakpoints, step over and into, and watch your local variables change.

81 worked example programs across 11 topics are built in, from your first printf to classes, the STL and file handling. Eight practice exercises give you a prompt, a hint, starter code and hidden test cases, then check your program's output against every case.

Your work is protected. Every save is atomic, so a crash never leaves a half-written file, and the workspace is snapshotted as you type - tabs, unsaved text, cursor position and breakpoints all come back after a power cut.

Also: multi-file projects that mix C and C++, one-key formatting with clang-format, light and dark themes, and static linking so the .exe files you build run on any Windows PC.

Free, with no advertising, no accounts and no telemetry. Developed by Bikash Chhetri.
